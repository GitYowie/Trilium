<h2>Implemented</h2>
<ul>
<li>Main grid load/edit/filter/sort/add/delete.</li>
<li>Nested subgrid editing for <code>json-array</code> fields.</li>
<li>Validation before save for main grid, subgrid, and nested subgrid.</li>
<li>Validation outputs:
<ul>
<li>Modal summary with row/field errors.</li>
<li>Inline per-cell error styling in subgrids.</li>
</ul>
</li>
<li>Numeric type enforcement keeps invalid text visible for validation (not silently sanitized).</li>
<li>Save with optional revision creation.</li>
<li>Save as child note and export JSON.</li>
</ul>
